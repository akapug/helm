## The recipe (from Tibo/@thsottiaux + Theo, 2.3M views — "claudex")

1. Install **CLIProxyAPI** (github.com/router-for-me/CLIProxyAPI) — a local proxy that
   speaks Anthropic's API format on one side and authenticates to OpenAI/Codex (OAuth
   subscription!), Gemini, Qwen, iFlow etc. on the other. THIS is the piece our earlier
   research missed: codex-family models under SUBSCRIPTION auth, no API key.
2. Point a claude-code seat at it via env:
   `ANTHROPIC_BASE_URL=http://127.0.0.1:<port>` + `ANTHROPIC_AUTH_TOKEN=<proxy-token>`.
3. Launch alias (the "claudex" pattern):
   ```
   CLAUDE_CODE_SUBAGENT_MODEL=gpt-5.6-sol \
   CLAUDE_CODE_ALWAYS_ENABLE_EFFORT=1 \
   CLAUDE_CODE_MAX_TOOL_USE_CONCURRENCY=3 \
   ENABLE_TOOL_SEARCH=false \
   claude --model gpt-5.6-sol
   ```
   (SUBAGENT_MODEL keeps spawned subagents on the same family; effort flag enables the
   model's effort controls; concurrency capped; dynamic tool search off.)

For **Kimi K3**: likely NO proxy needed — Moonshot ships a first-party Anthropic-compatible
endpoint (`https://api.moonshot.ai/anthropic`, see plans/multimodel-proxy-research.md).
Same for GLM/DeepSeek. CLIProxyAPI earns its place specifically for codex/OpenAI-family
(OAuth) and as a multi-provider router. Test both paths.

## HARD SAFETY RAILS (non-negotiable, from our research + house rules)

1. **NEVER put ANTHROPIC_BASE_URL in shared config** — not `~/.claude/settings.json`, not
   any shell profile. The tweet's version does; ours must NOT (it would hijack every Claude
   Max OAuth seat on the machine). Scope per-seat via an isolated `CLAUDE_CONFIG_DIR` (the
   cred-home pattern sesh already implements) or per-invocation env only.
2. **Claude seats stay on Max OAuth untouched** — no ANTHROPIC_API_KEY, no base-url
   override, ever (house rule). The proxy seam is ONLY for non-Claude families on their own
   auth. A rewriting proxy under Claude Max OAuth is a ToS/ban risk (buildr research,
   CONTEXT_NEVER_COMPACT_RESEARCH.md) — CLIProxyAPI here fronts OTHER providers' auth, which
   is fine.
3. Add `ANTHROPIC_BASE_URL`/`ANTHROPIC_AUTH_TOKEN` to the env-scrub list for Claude seats
   (mc's scrub-hook-env.sh pattern) so bleed is mechanically impossible.
4. Known compat risks to test for (from plans/multimodel-proxy-research.md): tool-call
   fidelity through translation, prompt-cache/cache_control drops (cost blowup on long
   loops), thinking-block/count_tokens handling, long-loop coherence. Gate a family's
   kanban rights on an agentic smoke: multi-tool loop + whisper receive/reply + subagent
   spawn.
