classify --labels L --source KIND [--consumer NAME] [--task TEXT] [--each-line] [--budget-ms N] [--json] | where | metrics [--consumer NAME] | label --consumer NAME --label ID | eval private-name — the thin, OPTIONAL client for the local classifier stream: text on stdin, 2-16 labels (JSON, id list, or @private-name), one typed answer (label, score, backend, ms) or a FAIL-OPEN naming why (unconfigured, unreachable, timeout, no-backend, too-long, refused-source, rejected, malformed, scrubbed). The backend is a host setting (HELM_CLASSIFY_BACKEND, else `backend` in <helm home>/_global/classify.json): none (a fresh install's: no call, no socket), openai-compatible (the classify contract at HELM_CLASSIFY_URL, the setting's url, or classify_url in the authored registry's host block) or jev (the Jev evaluator through the operator's AI gateway, its key in the environment variable key_env names, never in a file); the endpoint is never written in the source; only helm's own chat, ledger, lane diffs and helm-lane transcripts may be sent (--source), anything else is refused before a byte leaves. A classifier flags, a deterministic rule decides. Every call adds one row (consumer, source, label, score, ms, outcome; never the text) to a journal under helm's cache that `metrics` reads back per consumer; `label` records a hashed labelled example; `eval` measures a consumer's label set against its labelled set. The per-turn injection hook runs a SHADOW consumer (inject-shadow) on a host that set a backend: it scores the delivered jit lines of a lane room's turn inside HELM_CLASSIFY_INJECT_MS (default 300) and logs them on the fire-ledger row, changing nothing delivered. docs/CLASSIFY.md
